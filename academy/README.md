# Viva Academy — обучающая платформа для фармацевтов

Курсы, тесты и сертификаты для сотрудников аптек с личными кабинетами и кабинетом руководителя.

## Возможности
- 7 курсов × 3 урока, итоговые тесты-кейсы с пояснениями, проходной балл 80%.
- **Личный кабинет сотрудника**: вход по логину и паролю, прогресс хранится на сервере и виден с любого устройства, смена пароля.
- **Кабинет руководителя** (`#/admin`): все сотрудники с прогрессом, фильтр по аптекам и статусу, сводка по аптекам, детализация по курсам, добавление и блокировка сотрудников, импорт списка из Excel/CSV с автоматической генерацией паролей, выгрузка прогресса в Excel.
- Регистрация сотрудников по коду приглашения (включается в кабинете руководителя).
- Сертификаты с уникальным номером и публичной страницей проверки подлинности (`#/verify/<номер>`).
- Ответы тестов проверяются на сервере.
- Без сервера (например, при открытии файла с диска) сайт работает в демо-режиме и хранит прогресс в браузере.

## Требования к хостингу
- PHP 7.4 или новее с расширениями `pdo_mysql` и `mbstring` (есть на любом стандартном хостинге).
- MySQL 5.7+ или MariaDB 10.3+.
- HTTPS (Let's Encrypt).

## Установка (для системного администратора)
1. Загрузите **содержимое** папки `academy/` в корень сайта `vivaacademy.md` (`public_html` или `www`). Папку `tools/` загружать не обязательно.
2. В панели хостинга создайте базу данных MySQL (кодировка `utf8mb4`) и пользователя с полными правами на неё.
3. Скопируйте `api/config.sample.php` в `api/config.php` и впишите имя базы, пользователя и пароль.
4. Откройте в браузере `https://vivaacademy.md/api/install.php` — установщик создаст таблицы и первого администратора.
5. **Удалите файл `api/install.php` с сервера.**
6. Войдите на `https://vivaacademy.md` под администратором → «Руководителю» → добавьте сотрудников или импортируйте список.

На Apache файл `api/.htaccess` закрывает служебные файлы. На nginx добавьте аналогичное правило:

```nginx
location ~ ^/api/(?!index\.php|install\.php).+\.php$ { deny all; }
location ~ ^/data/ { deny all; }
```

## Импорт сотрудников
Колонки по порядку (разделитель `;`, `,` или табуляция; первая строка с заголовками допускается):

```
ФИО;логин;аптека;должность;пароль
Иванова Анна;ivanova.a;Аптека №1;Фармацевт;
```

Если пароль не указан, он будет создан автоматически. После импорта платформа один раз покажет логины и пароли и предложит скачать их файлом.

## Обновление контента
- Тексты уроков и вопросы — в `js/data.js`.
- После изменения вопросов тестов выполните `node tools/build-answers.js`, чтобы обновить ключ ответов `api/answers.php`.
- Перезалейте изменённые файлы на хостинг. `api/config.php` и база данных при этом не трогаются.

## Резервное копирование
Весь прогресс сотрудников хранится в базе MySQL. Включите ежедневный бэкап базы в панели хостинга.

## Структура
- `index.html`, `css/`, `js/` — интерфейс
- `api/index.php` — API (вход, прогресс, тесты, кабинет руководителя)
- `api/lib.php` — база данных, сессии, общие функции
- `api/install.php` — установщик
- `api/answers.php` — ключ ответов (генерируется из `js/data.js`)
