# Viva Academy — обучающая платформа для фармацевтов

Статический сайт без сборки и сервера: откройте `index.html` в браузере или опубликуйте папку `academy/` на любом хостинге (GitHub Pages, Netlify, хостинг vivaacademy.md).

## Возможности
- 7 курсов × 3 урока: консультирование и «красные флаги», ОРВИ и обезболивание, лекарственные взаимодействия, антибиотики, хранение и фармаконадзор, дермокосметика, сервис.
- Итоговые тесты-кейсы с пояснением каждого ответа, проходной балл 80%.
- Сертификат с номером и датой — печать или сохранение в PDF.
- Каталог с поиском и фильтром по направлениям, личный прогресс, светлая и тёмная темы, адаптивная вёрстка.

## Структура
- `index.html` — оболочка страницы
- `css/style.css` — стили
- `js/data.js` — **весь учебный контент** (курсы, уроки, вопросы). Чтобы добавить курс, допишите объект в массив `COURSES`.
- `js/app.js` — маршрутизация, прогресс, тесты, сертификаты

Прогресс хранится в `localStorage` браузера пользователя. Для единого учёта сотрудников (личные кабинеты, отчёты для руководителя) нужен серверный бэкенд.

## Публикация
Сайт публикуется на GitHub Pages автоматически при каждом изменении папки `academy/` в ветке `main` (workflow `.github/workflows/pages.yml`).

Однократная настройка: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

### Свой домен
1. Файл `academy/CNAME` уже содержит домен `learn.vivaacademy.md`.
2. У регистратора домена добавьте DNS-запись:
   - для поддомена: `CNAME learn → shvtesim-sudo.github.io`
   - для основного домена: четыре записи `A` на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
3. В **Settings → Pages** укажите тот же домен и включите **Enforce HTTPS**.
